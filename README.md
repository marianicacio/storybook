📚 Study Project – Componentes Estilizáveis com Storybook

Este repositório é um projeto de estudo utilizando o Storybook para desenvolver, documentar e testar componentes reutilizáveis e estilizados de forma isolada.

O objetivo principal é construir uma base sólida para criação de um design system escalável, com foco em:

🔁 Reutilização

🎨 Customização via props

🧪 Testes visuais isolados

📖 Documentação interativa

♿ Boas práticas de acessibilidade

🚀 Tecnologias Utilizadas

⚛️ React

🧩 Storybook

🎯 Objetivos do Projeto

Criar componentes altamente configuráveis

Trabalhar com variantes (ex: primary, secondary, outline)

Aplicar design tokens (cores, espaçamentos, tipografia)

Documentar props e estados no Storybook

Simular cenários reais de uso

Melhorar organização e arquitetura de UI


🧪 Executando o Projeto

Instale as dependências:

npm install

Rode o Storybook:

npm run storybook

Acesse:

http://localhost:6006

📚 O que estou estudando aqui

Arquitetura de componentes

Separação entre lógica e estilo

Composição vs herança

Design System

Controle de estados visuais

Documentação viva de UI


💡 Sobre o Storybook

O Storybook permite desenvolver componentes de forma isolada da aplicação principal, facilitando:

Visualização de diferentes estados

Testes manuais

Documentação automática

Padronização visual
